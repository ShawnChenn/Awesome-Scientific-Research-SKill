# Tone Guidelines — 语气与表述指南

## 推荐语气

- **专业**：用学科术语、基于证据，非聊天式
- **克制**：避免夸张、绝对化表述，承认不确定性
- **具体**：每条回应指向论文位置或实验数字，非泛泛而谈
- **非对抗**：即使温和反驳，也保持尊重

## 推荐表达（模板句）

- "感谢审稿人指出这一点，我们同意该问题需要更清楚地说明……"
- "我们理解该 concern 的来源，并补充解释如下……"
- "这一点确实是当前版本的限制，我们将在 rebuttal / camera-ready 中明确说明……"
- "为回应这一问题，我们计划补充……；在当前输入范围内，我们暂不声称已有结果。"
- "我们尊重审稿人的观察，已在对应位置增强了表述的清晰度。"

## 避免表达

| 避免 | 原因 | 改写方向 |
| :--- | :--- | :--- |
| "审稿人误解了我们的工作" | 归咎对方，失分 | "论文表述仍可更清楚地说明……" |
| "这个问题其实不重要" | 忽视 reviewer concern | "我们理解该 concern，已在 limitations 中讨论" |
| "显然" | 傲慢、无信息 | 删除或用事实替换 |
| "我们的方法全面优于已有方法" | 绝对化，站不住 | "在 X 指标上，我们的方法比 Z 提高了 Y%" |
| "审稿人可能忽略了……" | 暗示对方不仔细 | "我们在此重申：如 §X 所述……" |

## 改写原则

1. **把情绪性防御改写为信息性澄清。**
   - ✗ "我们不同意" → ✓ "感谢指出；我们补充说明如下……"
2. **把绝对化表述改写为基于证据的限定表达。**
   - ✗ "我们的方法最好" → ✓ "在基准 A 上，我们的方法达到了 Y，优于基线 B 和 C"
3. **把无法支持的承诺改写为可执行的补充计划。**
   - ✗ "我们将在终稿中全面改进 X" → ✓ "我们计划补充 X 实验[具体操作]，预计验证 Y 假设"
4. **把 reviewer 的误解归咎改写为论文自身的表达改进空间。**
   - ✗ "您在 §4.2 中没看懂" → ✓ "§4.2 的表述可以更清楚地解释 Z 的推导过程"

# Quality Scoring — 多维度质量评分

对改写后的文本进行 1–10 分评估（总分 **/50**）：

| 维度 | 评估标准 | 得分 |
| :--- | :--- | :--- |
| **直接性** | 直接陈述事实还是绕圈宣告？10分：直截了当；1分：充满铺垫 | /10 |
| **节奏** | 句子长度是否变化？10分：长短交错；1分：机械重复 | /10 |
| **信任度** | 是否尊重读者智慧？10分：简洁明了；1分：过度解释 | /10 |
| **真实性** | 听起来像真人说话吗？10分：自然流畅；1分：机械生硬 | /10 |
| **精炼度** | 还有可删减的内容吗？10分：无冗余；1分：大量废话 | /10 |
| **总分** | 五维合计 | **/50** |

## 评分标准

| 分数 | 评级 | 说明 |
| :--- | :--- | :--- |
| 45–50 | ✅ 优秀 | 已彻底去除 AI 痕迹，可交付 |
| 35–44 | ⚠️ 良好 | 大部分 AI 痕迹已清除，仍有改进空间 |
| 25–34 | ❌ 需改进 | 残留明显 AI 特征，需要重新修订 |
| <25 | ❌ 失败 | AI 味道过重，建议从头改写 |

## 评分细则

### 直接性（/10）
- 10：无任何"标志着""作为……证明""强调"类宣告
- 7：少量但无害的过渡词
- 4：多处出现"此外""然而"等连接词
- 1：几乎每段都在宣告意义

### 节奏（/10）
- 10：短句 3-8 字、长句 15-25 字自然交错
- 7：句子长度有变化但有限
- 4：连续 3+ 句长度几乎相同
- 1：全部句子结构一致

### 信任度（/10）
- 10：直接陈述，信任读者自行理解
- 7：偶有解释性插入，但不啰嗦
- 4：频繁解释隐喻、过度引导
- 1：像在给小学生讲课

### 真实性（/10）
- 10：读起来像该领域的真人写的
- 7：整体自然，个别处略显机械
- 4：多处僵硬表达，缺乏个人声音
- 1：从头到尾像维基百科条目

### 精炼度（/10）
- 10：每个词都有用，无废话
- 7：大部分干净，少数冗余
- 4：可删减 20-30%
- 1：可删减 50% 以上

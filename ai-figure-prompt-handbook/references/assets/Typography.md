# Typography

Use typography as hierarchy:

- Figure title: short, claim-oriented, optional for paper figures.
- Section headers: 2-4 words.
- Module labels: noun phrases.
- Annotations: short verb phrases explaining transformation or consequence.
- Equations: only essential symbols that anchor the method.

## Rules

- Use a modern sans-serif style.
- Keep label sizes visibly distinct: title > region header > module label > annotation.
- Avoid all-caps except tiny badges.
- Avoid long sentences inside diagrams.
- Use consistent capitalization.

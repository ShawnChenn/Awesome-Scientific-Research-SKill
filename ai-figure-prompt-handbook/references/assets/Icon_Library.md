# Icon Library

Use simple semantic icons or glyphs. Prefer consistent stroke width and filled/outline style.

## Common Research Metaphors

- Dataset: stacked cards, table grid, database cylinder.
- Model: rounded module, chip, layered blocks.
- Tokens/text: small pills or document lines.
- Image/video: frame, thumbnail grid, timeline strip.
- Graph: connected nodes.
- Optimization: target, curve, slider, gradient arrow.
- Loss/reward: badge, scale, sparkline.
- Evaluation: checklist, chart, magnifier.
- Human feedback: speech bubble, rating chips.
- Memory/retrieval: archive box, index cards, search lens.

## Rules

- Icons should label structure, not decorate empty space.
- Use no more than one icon style.
- Avoid generic robot heads unless the research subject specifically requires agents or robotics.

# Color System

Use restrained, semantic palettes. Start with neutral background and dark text, then add 2-3 accent colors.

## Recommended Roles

- Background: `#F8FAFC` or white.
- Text: `#0F172A`.
- Secondary text: `#475569`.
- Data: blue or cyan.
- Model/method: indigo, violet, or deep teal.
- Supervision/objective: amber.
- Result/success: green.
- Warning/failure/baseline limitation: muted red or orange.

## Rules

- Assign one meaning per color and keep it consistent.
- Use accent color for contribution, not every object.
- Avoid rainbow palettes unless category count requires it.
- Avoid neon, glossy gradients, and low-contrast pastel text.

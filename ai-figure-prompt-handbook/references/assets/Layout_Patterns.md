# Layout Patterns

Choose layout by story type:

- Linear flow: pipelines, training stages, inference, data transformations.
- Hub-and-spoke: central method with supporting modules.
- Zoom-in: framework context plus detailed module internals.
- Split comparison: baseline vs proposed, before vs after, failure vs solution.
- Matrix: taxonomies, ablations, trade-offs, method families.
- Layered stack: representation levels, hierarchy, multimodal fusion.
- Loop: iterative refinement, agent feedback, optimization cycles.

## Spacing Rules

- Use 3-5 major regions.
- Keep equal margins and aligned card edges.
- Use arrows sparingly; every arrow must encode order, dependency, or transformation.
- Prefer grouped cards over scattered labels.
- Reserve the largest visual weight for the main contribution.

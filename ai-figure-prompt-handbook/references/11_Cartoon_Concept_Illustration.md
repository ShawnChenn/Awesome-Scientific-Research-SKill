# Cartoon Concept Illustration

Use for conceptual analogies, approachable explainers, or lightweight editorial illustrations supporting a scientific idea.

## Narrative Shape

Use metaphor carefully:

1. Scientific concept.
2. Concrete analogy.
3. Mapping between analogy and research components.
4. One clear takeaway.

## Prompt Skeleton

```text
Design a clean cartoon-style concept illustration for [SCIENTIFIC CONCEPT]. Use the metaphor [METAPHOR] to explain [TAKEAWAY].

Keep the style simple, charming, and academically appropriate. Use flat vector shapes, minimal characters or objects, and clear labels that map metaphor elements to scientific elements. The illustration should clarify the concept, not distract from it.

Use these labels: [LABELS]. Avoid childish detail, meme style, exaggerated expressions, photorealism, and ambiguous metaphors.
```

## Design Checks

- Does the metaphor map cleanly to the scientific concept?
- Is the tone suitable for a paper, slide, or media explainer?
- Can the image be understood without a long explanation?

# Poster Figure

Use for conference poster centerpieces, overview panels, or large-format academic visuals.

## Narrative Shape

Use large-scale scanning:

1. Central claim or framework.
2. Surrounding evidence panels.
3. Clear reading path.
4. Strong section hierarchy.

## Reference Samples

When the user explicitly asks for a poster-style figure, read [Poster_Sample_References.md](Poster_Sample_References.md) for layout and density cues.

## Prompt Skeleton

```text
Design a conference-poster figure for [PROJECT]. It should serve as the main visual anchor of the poster and explain: [CLAIM].

Use a large-format layout with a dominant central framework and surrounding evidence panels. Make typography readable from distance. Use strong section headers, consistent module cards, and generous spacing. Place the most important contribution in the center or upper third.

Include these sections: [SECTIONS]. Use only essential labels. Avoid paper-column density, excessive arrows, and small caption-like text.
```

## Design Checks

- Is the main idea visible from several feet away?
- Are secondary details grouped into scannable regions?
- Does the figure support oral explanation at a poster session?

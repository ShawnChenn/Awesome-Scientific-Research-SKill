# Motivation / Comparison Figure

Use for problem gaps, failure modes, research motivation, why the method is needed, or fused motivation-plus-comparison figures.

## Narrative Shape

Use contrast:

1. Existing setting or assumption.
2. Failure, bottleneck, or mismatch.
3. Desired capability.
4. Proposed conceptual remedy.

## Reference Samples

When the user explicitly asks for a motivation or fused motivation-plus-comparison figure, read [Motivation_Comparison_Samples.md](Motivation_Comparison_Samples.md).

## Prompt Skeleton

```text
Create a motivation figure for a research paper on [TOPIC]. The purpose is to make this problem obvious: [PROBLEM].

Use a two- or three-panel editorial layout. Panel A shows the conventional approach and its limitation. Panel B shows the failure mode or gap using a clear visual metaphor. Panel C shows the proposed direction as a concise conceptual solution. Use semantic contrast: muted colors for the limitation, clearer accent color for the proposed idea.

Include minimal labels: [LABELS]. Use clean vector illustrations, simple data/model icons, and restrained annotations. The figure should feel like a polished conference-paper teaser, not a cartoon meme or marketing banner.
```

## Design Checks

- Is the problem understandable before the method is known?
- Is the failure mode visible, not buried in text?
- Does the proposed idea look like an answer to the visualized gap?

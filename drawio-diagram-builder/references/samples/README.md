# Draw.io Diagram Builder — Reference Samples

本目录用于存放 draw.io 输出截图样例，作为参考图复现和迭代修正的视觉基准。

## 推荐添加的样例类型

| 类型 | 说明 | 命名建议 |
| :--- | :--- | :--- |
| Method Architecture | 论文方法架构图 | `method-architecture-01.png` |
| System Pipeline | 系统流程图 | `system-pipeline-01.png` |
| Comparison Layout | 对比图布局 | `comparison-layout-01.png` |
| Training Flow | 训练流程图 | `training-flow-01.png` |
| Motivation Diagram | 动机图 / gap illustration | `motivation-01.png` |

## 如何添加

1. 使用 draw.io 创建或复现一个图表
2. 在 draw.io 中导出为 PNG（File → Export as → PNG）
3. 将截图放入本目录，按上述命名规范命名
4. 在 `SKILL.md` 或提示词中引用该样例路径

## 注意事项

- 截图分辨率建议 2x（Retina），确保文字清晰
- 保留 `.drawio` 源文件便于后续迭代
- 每张样例图对应一个具体的图表类型或布局模式
